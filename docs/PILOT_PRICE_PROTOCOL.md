# Protocolo de piloto para validar precios

1. Cargar caso real con placa, fotos y ubicación.
2. Generar BOM y PriceGuard.
3. Revisar líneas amarillas y rojas.
4. Enviar RFQ a mínimo 3 proveedores cuando haya rojo o precio sensible.
5. Actualizar catálogo con precio confirmado, vigencia y proveedor.
6. Exportar propuesta premium.
7. Registrar si la cotización fue ganada o perdida.
8. Ajustar márgenes y contingencias según mercado real.

Métrica principal: horas ahorradas por cotización y diferencia entre precio estimado y precio confirmado.

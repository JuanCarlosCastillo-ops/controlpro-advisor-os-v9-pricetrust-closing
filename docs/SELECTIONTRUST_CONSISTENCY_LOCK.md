# SelectionTrust Consistency Lock

Toda salida debe obedecer la cadena: datos → cálculo → arquitectura → BOM → cables/borneras → sensores → presupuesto → propuesta.

Bloqueos críticos:
- FLA real vs estimado >35% baja confianza y bloquea propuesta fuerte.
- Sensor citado en control/riesgos debe existir en BOM.
- Cable calculado debe coincidir con BOM y lista de cables o justificar RFQ.
- Precio verde no existe si FitLock está rojo.

# OptionTrust Decision Protocol

ControlPro V15 no entrega una sola respuesta por defecto. Evalúa arranque directo, inversión por contactores, estrella-triángulo, soft starter, VFD y PLC/HMI cuando aplica. Cada alternativa recibe BOM, presupuesto, MathTrust, PriceGuard, FitLock y RFQ propios.

Regla comercial: la recomendación principal debe ser la mejor relación entre objetivo del cliente, riesgo, costo, datos disponibles y mantenimiento; VFD no se recomienda automáticamente si DOL o soft starter resuelven mejor el caso.

# Diccionario de datos

## Entrada crítica

- `motor_power_hp`: potencia del motor.
- `voltage`: tensión real.
- `phases`: fases.
- `full_load_amps`: corriente de placa.
- `application`: tipo de equipo.
- `cable_run_m`: distancia tablero-motor.
- `environment`: ambiente de instalación.
- `needs_brake`, `needs_limit_switches`, `needs_estop`: seguridad crítica para izaje.
- `short_circuit_available_ka`: dato para liberar SCCR/kAIC.

## Salida clave

- `data_quality`: calidad de datos.
- `consistency_audit`: coherencia técnica.
- `market.price_decisions`: selección de precios.
- `budget`: presupuesto.
- `release_gates`: compuertas de salida.
- `quote_readiness`: preparación de cotización.
- `assumption_ledger`: supuestos visibles.

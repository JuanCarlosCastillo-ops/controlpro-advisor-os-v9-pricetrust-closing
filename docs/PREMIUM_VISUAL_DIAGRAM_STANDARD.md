# Premium Visual & Diagram Standard

V16 separa visuales en tres niveles:

1. **Vista cliente**: visual dinamico del caso con maquina, tablero, arquitectura, FitLock, PriceGuard, breaker, conductor y RFQ.
2. **Ingenieria**: SVG CAD-like E-001/E-002/E-003 segun arquitectura: DOL, estrella-triangulo, soft starter, VFD o PLC/HMI.
3. **Taller**: lista de cables, borneras y Draw.io editable para formalizar en CAD real.

Regla: si algo aparece en control o diagrama, debe estar en BOM o quedar marcado como pendiente/RFQ. Si el BOM contradice calculo, se bloquea.

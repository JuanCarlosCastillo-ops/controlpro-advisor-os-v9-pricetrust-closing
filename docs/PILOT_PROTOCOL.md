# Protocolo de prueba piloto

## Objetivo

Probar con ingenieros eléctricos si ControlPro ahorra tiempo real en cotización y entrega un expediente que el humano pueda revisar sin reconstruir.

## Prueba sugerida

1. Tomar 3 casos reales: guinche, compresor y bomba/tablero.
2. Medir cuánto tarda el ingeniero en cotizar manualmente.
3. Medir cuánto tarda usando ControlPro.
4. Revisar calidad del BOM, presupuesto, riesgos, RFQ y propuesta.
5. Registrar correcciones necesarias.

## Métricas

- Tiempo ahorrado.
- Errores detectados.
- Ítems que requieren RFQ.
- Porcentaje de BOM útil sin edición.
- Confianza comercial del precio.
- Carga de corrección humana.

## Criterio de éxito

El piloto funciona si reduce 50–80% del tiempo de pre-cotización y entrega un material que el ingeniero solo tenga que ajustar, no rehacer.

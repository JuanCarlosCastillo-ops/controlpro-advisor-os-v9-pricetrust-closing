# Criterios de cierre piloto V14

Antes de enseñar la app a ingenieros externos:

- La app debe ejecutar sin errores.
- El caso demo debe generar expediente completo.
- El PDF debe renderizar sin texto cortado.
- El catálogo debe cubrir los componentes principales.
- El panel de PriceGuard debe mostrar verdes/amarillos/rojos.
- El RFQ debe salir listo para copiar.
- Las APIs deben mostrar estado real de credenciales.
- El producto no debe fingir precios confirmados sin proveedor.

# Machine Context Lock - V12

ControlPro no puede usar la misma plantilla para todo. La V12 clasifica la máquina y ajusta salidas:

- Guinche / izaje: freno, finales, carga suspendida, E-Stop, rampas y pruebas con carga supervisada.
- Compresor: presostato, unloader/descarga, válvula de alivio, temperatura, ventilación y arranques por hora.
- Bomba: trabajo en seco, nivel, presión, caudal, cavitación y golpe de ariete.
- Banda transportadora: guardas, pull-cord, desalineación, atasco y alarma previa.
- Motor general: sobrecarga, pérdida de fase, ambiente, E-Stop y rotulado.

La regla es simple: **lo que sale en PDF, Markdown, BOM, CAD/taller, RFQ y propuesta debe obedecer el contexto de máquina**.

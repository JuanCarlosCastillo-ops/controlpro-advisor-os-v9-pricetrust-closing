# Criterios de precios y RFQ

ControlPro separa precios en cuatro niveles:

1. Estimado: cálculo/rango interno; requiere RFQ.
2. Referencial: base o catálogo no confirmado.
3. Referencial fuerte: fuente reciente, proveedor conocido o stock probable.
4. Confirmado: proveedor respondió con precio, stock, marca, entrega y vigencia.

Regla: si el proyecto mueve miles de dólares, el precio final debe mostrar fuente, fecha, confianza y vigencia.
